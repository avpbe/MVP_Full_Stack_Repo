# Frontend - Sistema de Requisições de Engenharia
  
Esta é uma SPA (Single Page Application) desenvolvida para consumir a API de gerenciamento de requisições de engenharia. A aplicação foi construída utilizando apenas HTML, CSS e JavaScript puro, sem o uso de frameworks como React, Vue ou Angular.
  
## Funcionalidades
  
- **Visualização de Requisições**: Exibe todas as requisições cadastradas em formato de cards.
- **Criação de Requisição**: Permite adicionar uma nova requisição através de um formulário.
- **Remoção de Requisição**: Permite deletar uma requisição existente.
- **Busca**: Filtra as requisições pelo nome do projeto (funcionalidade a ser implementada no `scripts.js`).
  
---
  
## Instruções de Execução
  
### Pré-requisitos
  
1. A **API backend** deve estar em execução (`http://127.0.0.1:5000`).
2. Um navegador web moderno (Chrome, Firefox, Edge, etc.).
  
### Como Rodar
  
Basta abrir o arquivo `index.html` diretamente no seu navegador. Não é necessário nenhum servidor web ou dependência adicional para executar o frontend.
